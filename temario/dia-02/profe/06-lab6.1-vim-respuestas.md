# Solución

Las partes 2 a 5 son secuencias de teclas dentro de vim. Se dictan una por una, esperando a que todos la hagan antes de la siguiente.

## Parte 1
```bash
cat > ~/empresa/documentos/app.conf <<'CONF'

CONF
cat ~/empresa/documentos/app.conf
grep -c srv-old ~/empresa/documentos/app.conf
```

## Parte 2
```bash
vim ~/empresa/documentos/app.conf
```
1. `:set nu` `Enter` → aparecen los números.
2. `/srv-old` `Enter` → salta a la línea 2.
3. `n` → línea 7. `n` → línea 9. `n` → vuelve a la 2.
4. `:q` `Enter` → sale (no hubo cambios, no se queja).

## Parte 3
```bash
vim ~/empresa/documentos/app.conf
:noh - para quitarlo

```
1. `:%s/srv-old/srv-new/g` `Enter` → abajo dice `3 substitutions on 3 lines`.
:%s/srv-old/srv-new/g
│ │ │       │       └ g =  (sin g, solo la primera de cada línea)
│ │ │       └ por qué texto reemplazar
│ │ └ qué texto buscar
│ └ s = sustituir
└ % = en todo el archivo

2. `G` → última línea.
3. `o` → línea nueva debajo, ya en modo escribir.
4. Escribir `# modificado por student`.
5. `Esc`.
6. `:wq` `Enter`.

```bash
grep -n "srv-" ~/empresa/documentos/app.conf
tail -1 ~/empresa/documentos/app.conf
```

## Parte 4
```bash
vim ~/empresa/documentos/app.conf
```
1. `i` → escribir cualquier cosa, por ejemplo `xxxx`.
2. `Esc`.
3. `:q` `Enter` → `E37: No write since last change (add ! to override)`.
4. `:q!` `Enter` → sale.

```bash
head -2 ~/empresa/documentos/app.conf
```

## Parte 5
```bash
vim ~/empresa/documentos/app.conf
```
1. `gg` → primera línea.
2. `yy` → la copia.
3. `p` → la pega debajo (ahora hay dos líneas de comentario iguales).
4. `dd` → borra la copia.
5. `u` → deshace: la copia vuelve.
6. `Ctrl+R` → rehace: la copia se va otra vez.
7. `:wq` `Enter`.

```bash
wc -l ~/empresa/documentos/app.conf
```
