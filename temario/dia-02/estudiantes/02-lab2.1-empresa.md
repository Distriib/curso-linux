# Lab 2.1 — Construir `~/empresa`

Se hace por partes, solos. Cada parte tiene un **Comprobar** con lo que tienen que ver. Cuando todos lo tienen, se pasa a la siguiente.

Todo va en el home: `~/empresa` = `/home/student/empresa`.

---

## Parte 1 — Las carpetas

Crear la carpeta `empresa` en el home, con cuatro carpetas adentro: `documentos`, `clientes`, `backups`, `logs`.

**Comprobar:**
```bash
tree ~/empresa
```
```
/home/student/empresa
├── backups
├── clientes
├── documentos
└── logs

4 directories, 0 files
```

---

## Parte 2 — Los archivos

Adentro de `documentos`:
- Cinco archivos: `informe1.txt`, `informe2.txt`, `informe3.txt`, `informe4.txt`, `informe5.txt`. Cada uno con una línea de texto adentro: `Informe numero 1`, `Informe numero 2`, etc.
- Dos archivos vacíos: `plan-2026.doc` y `presupuesto.csv`.

**Comprobar:**
```bash
ls ~/empresa/documentos
cat ~/empresa/documentos/informe3.txt
```
```
informe1.txt  informe2.txt  informe3.txt  informe4.txt  informe5.txt  plan-2026.doc  presupuesto.csv
Informe numero 3
```

---

## Parte 3 — Copiar, mover, renombrar

1. **Copiar** `informe2.txt` a `clientes/` (queda en los dos lados).
2. **Mover** `informe5.txt` a `clientes/`, y que en el camino pase a llamarse `cliente-acme.txt` (desaparece de `documentos`).
3. **Copiar** `informe1.txt` como `copia-informe1.txt`, y después **renombrar** esa copia a `borrador.txt`.

**Comprobar:**
```bash
ls ~/empresa/documentos ~/empresa/clientes
```
```
/home/student/empresa/clientes:
cliente-acme.txt  informe2.txt

/home/student/empresa/documentos:
borrador.txt  informe1.txt  informe2.txt  informe3.txt  informe4.txt  plan-2026.doc  presupuesto.csv
```

---

## Parte 4 — Enlaces

Todo adentro de `documentos`:
1. Crear `politica.txt` con el texto `Politica de respaldos v1`.
2. Hacerle un **enlace duro** llamado `politica-hard.txt`.
3. Hacerle un **enlace simbólico** llamado `politica-link.txt` — con la ruta absoluta.
4. Agregar al final una segunda línea, `Politica de respaldos v2` — pero en el comando usar el nombre `politica-hard.txt`, no `politica.txt`. Después hacer `cat politica.txt`: ¿apareció la línea ahí también?
5. **Borrar** `politica.txt`. Hacer `cat` de los dos enlaces: ¿cuál sigue funcionando?
6. **Renombrar** `politica-hard.txt` a `politica.txt`. Hacer `cat` del simbólico otra vez.

**Comprobar:**
```bash
ls -li ~/empresa/documentos/politica*
cat ~/empresa/documentos/politica-link.txt
```
```
17512441 lrwxrwxrwx. 1 student student 45 ... politica-link.txt -> /home/student/empresa/documentos/politica.txt
17512440 -rw-r--r--. 1 student student 50 ... politica.txt
Politica de respaldos v1
Politica de respaldos v2
```
(Los números de inodo van a ser otros. Lo que importa: son distintos, y el `cat` muestra las dos líneas.)

## Parte 5 — Un enlace desde el home

Crear `~/logs-empresa` como enlace simbólico a `~/empresa/logs`.
