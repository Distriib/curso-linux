# Día 5 — Redes, DNS y SSH

**4 horas**

## Qué vamos a hacer

1. **Conceptos de red** (30 min) — IP, máscara, gateway, DNS y puertos
2. **Inspeccionar** (35 min) — `ip`, `ss`, `ping` y `dig`: qué tiene el servidor
3. **Configurar IP fija** (55 min) — NetworkManager con `nmcli`, DNS y rutas
4. **SSH a fondo** (45 min) — Claves, acceso sin contraseña, copiar archivos y túneles
5. **Diagnóstico por capas** (25 min) — Método ordenado para encontrar dónde se corta

## Al terminar

Dejar un servidor con IP fija y acceso por clave, y diagnosticar una falla
de red paso a paso hasta repararla.
