## Parte 2 — Los cuatro archivos

```bash
ls -l /etc/passwd /etc/shadow /etc/group /etc/gshadow
cat /etc/shadow
```

**Pregunta:** ¿por qué puedo leer `passwd` y no `shadow`? ¿Qué dicen los permisos de cada uno?

**Comprobar:**
```
-rw-r--r--. 1 root root ... /etc/group
----------. 1 root root ... /etc/gshadow
-rw-r--r--. 1 root root ... /etc/passwd
----------. 1 root root ... /etc/shadow
cat: /etc/shadow: Permission denied
```

## Parte 3 — Leerlos como root

```bash
getent passwd student
sudo grep student /etc/shadow
```

**Pregunta:** en `passwd`, ¿qué hay en cada campo? En `shadow`, ¿qué es lo que empieza con `$6$`? ¿Por qué `sudo` sí pudo leerlo si el archivo dice `----------`?

**Comprobar:**
```
student:x:1000:1000:student:/home/student:/bin/bash
student:$6$...:NNNNN:0:99999:7:::
```

## Parte 4 — Quién administra y quién está conectado

```bash
getent group wheel
who
w
last -n 5
```

**Pregunta:** ¿quién es miembro de `wheel`? ¿Qué tiene que ver eso con que yo pueda usar `sudo`? ¿Desde qué dirección estoy conectado?

**Comprobar:**
```
wheel:x:10:student
student  pts/0  ...  (10.0.2.2)
```
En `last`, `student ... still logged in` y una línea `reboot`.
