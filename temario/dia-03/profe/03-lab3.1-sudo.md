# Solución

## Parte 1
```bash
su ana -c 'pwd; echo "HOME=$HOME MAIL=$MAIL"'
su - ana -c 'pwd; echo "HOME=$HOME MAIL=$MAIL"'
```
(pide la contraseña de ana las dos veces)

## Parte 2
```bash
sudo -i
```
Como root:
```bash
whoami; pwd; umask; exit
```

## Parte 3
```bash
su - pedro
```
Como pedro:
```bash
sudo -l
sudo cat /etc/shadow
exit
```

## Parte 4
```bash
sudo visudo -f /etc/sudoers.d/soporte
```
En vim: `i`, escribir la línea, `Esc`, `:wq`.
```
%soporte ALL=(root) /usr/bin/systemctl restart chronyd, /usr/bin/systemctl status chronyd
```
```bash
sudo visudo -c
ls -l /etc/sudoers.d/soporte
```

Si alguien deja un `sudoers.d/soporte` roto y a nadie le funciona `sudo`: `su -` (clave de root) y `rm /etc/sudoers.d/soporte`.

## Parte 5
```bash
su - pedro
```
Como pedro:
```bash
sudo -l
sudo systemctl restart chronyd
systemctl is-active chronyd
sudo systemctl restart sshd
sudo cat /etc/shadow
exit
```
